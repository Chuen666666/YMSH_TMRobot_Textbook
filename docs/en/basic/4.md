# 4. Login and Permissions

## Power On

After connecting the power and monitor, press `POWER` on the controller to start the robot arm.

## Getting Permission

1. Click `≡` in the top-left corner, then click <img src="/people_icon.jpg" alt="Login icon" style="width: 25px; display: inline; vertical-align: middle; margin: 0 5px;"> to open the login window. The newer interface pops this up automatically after boot, so this step can be skipped there.
2. Log in with **Administrator** permission. The default has no password, so just click `OK`.
3. Click `Get Control` (the newer interface usually has control by default, so this can be skipped), then press `M/A` on the controller to switch to manual mode. A blue light means automatic mode; a green light means manual mode.
4. Click `≡`, then click <img src="/TM_project_icon.png" alt="Project icon" style="width: 25px; display: inline; vertical-align: middle; margin: 0 5px;"> to enter the project page. Create a new project before writing a project. Always use `TMFlow`.
