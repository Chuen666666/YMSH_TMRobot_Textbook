## The Buttons

### The Big Red Button

On the older controller, to the right of the six smaller buttons, there is a very big, very red button. That is the emergency stop.

Normally you do not need to touch it. Once it is pressed, the robot arm cuts power and stops immediately. In 99.99% of cases, you will not use it. But if you accidentally press it, for example by dropping the controller and slamming the button down, turn the red button clockwise all the way, then pull it upward to release the emergency stop.

### The Six Small Buttons

To the right of the emergency stop are six function buttons. From top to bottom and left to right, they are:

- <img src="/power.png" alt="POWER button icon" style="width: 30px; display: inline; vertical-align: middle; margin: 0 5px;"> `POWER`: used to power on the robot arm
- <img src="/stop.png" alt="STOP button icon" style="width: 30px; display: inline; vertical-align: middle; margin: 0 5px;"> `STOP`: stops a running project or motion, or exits certain pages
- <img src="/ma.png" alt="M/A button icon" style="width: 30px; display: inline; vertical-align: middle; margin: 0 5px;"> `M/A`: switches between manual and automatic mode; after startup, switch to manual mode before operating
- <img src="/play.png" alt="PLAY/PAUSE button icon" style="width: 30px; display: inline; vertical-align: middle; margin: 0 5px;"> `PLAY/PAUSE`: starts or pauses a project, and in some operations you must hold it as instructed
- <img src="/plus.png" alt="+ button icon" style="width: 30px; display: inline; vertical-align: middle; margin: 0 5px;"> `+`: fine-tunes coordinate values, adjusts project speed, or is held during some prompted operations
- <img src="/minus.png" alt="- button icon" style="width: 30px; display: inline; vertical-align: middle; margin: 0 5px;"> `-`: fine-tunes coordinate values or adjusts project speed
